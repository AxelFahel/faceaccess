# Plano de Evolução (Roadmap) — FaceAccess

## Versão 1.1 (Próximas Entregas)
- Suporte a leitor físico de QR Code serial/USB no Modo Kiosk.
- Integração de relés físicos via protocolo MQTT / Wiegand local.
- Relatórios em formato PDF com biblioteca nativa.

## Versão 1.2
- Suporte a múltiplos totens distribuídos em subredes locais segregadas.
- Cache distribuído com Redis para suporte a múltiplas instâncias de backend balanceadas.
- Sincronização offline-first para terminais operando temporariamente sem conexão com a base central.
